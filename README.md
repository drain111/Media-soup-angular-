In this project I will try to create a voicechat app using the mediasoup server on the backend, and angular on the frontend to learn angular.
The server variables in env.production.example are needed to run it, with the exception of CLIENTIDGOOGLE=
CLIENTSECRETGOOGLE=

CUSTOM_ISSUER=
CUSTOM_CLIENT_ID=
CUSTOM_CLIENT_SECRET=
ISSUER=
Those are only if you use google or if you use a custom identity provider
